# 经验卡 · 视觉验收技法（跨类技法）

> **本卡是技法，不是问题类。** 它嵌入在 UI/UX 复刻、内容再创作、能力图谱等类里。

- **类型**：跨类技法
- **身份**：产品经理 / 商业分析
- **support**：技法出现在 **443/2,794 = 16%** 的会话中。分布：
  - **06 内容提取 48%**
  - **UI/UX 类 47%**
  - 07 能力图谱 29%
  - 01 只读审计 11%
- **置信级**：中
- **脚手架判定**：**部分脚手架**。`screenshot`(19 文件)、`preview`(23)、`Playwright`(13) 在配置/技能文档里；
  **涌现部分**：`抽检`(0 文件)、`像素`(0)、`对比`(1)、`截图`(1) → **"渲染抽检 + 像素对比"是涌现**
- **口径**：全量

## 场景

改了 UI / 做了原型复刻 / 生成了可视化产物，需要确认"它真的看起来对"，而不只是"代码没报错"。

## 问题

- 只看代码 → 不知道渲染出来是什么样。
- 只看一次截图 → 看不出与目标的偏差。
- 截图工具不可用 → 就放弃视觉验证？还是在没有证据的情况下宣称"没问题"？

## 解决方案（收敛解）

**视觉验收 = 渲染抽检 + 像素/结构对比 + 证据边界诚实。**

核心三点：**实际渲染抽检**（不是看代码）、**多状态对比**（不是看一次）、**截图不可用时诚实标证据边界并用替代证据兜住**。

## 技法（嵌入任意产出类）

| 步 | 动作 | 触发 | 决策点 |
|---|---|---|---|
| V0 | **搭真实渲染环境**（本地服务器 / 驱动真实浏览器） | 有 UI 产物 | 包装器拦截 → 起本地 127.0.0.1 服务器渲染 |
| V1 | 生成预览/截图（多视口、多状态：hover / 空状态 / 移动端） | 有 UI 或可视化产物 | 截图工具不可用 → 见 V5 |
| V2 | **对比**：与目标 / 上一版 / 设计稿逐项比 | 有参照物 | 无参照 → 用清单逐项核 |
| V3 | **批判性检查偏差**：层级 / 间距 / 一致性 / 配色 / 可访问性 | 总是 | 只看"有没有" → 不够，要看"对不对" |
| V4 | **渲染抽检**：确认关键页在**实际渲染中可读** | 有文档/报表产物 | 只验数据不验渲染 → 漏 |
| V5 | **截图不可用 → 诚实标证据边界，用替代证据兜住** | 工具/网络受限 | 禁止在无证据时宣称"没问题" |
| V6 | 标注"本地 vs 线上"（当前验的是哪个） | 总是 | 混标 → 误判已验证范围 |
| V7 | 清理临时资源（停服务器 / 重置视口 / 销毁 iframe） | 用完即清 | 残留 → 污染环境 |
| V8 | 把发现锁进回归测试 | 发现真缺陷 | 只口头报 → 会复发 |
| V9 | 只读边界（除非发现缺陷才转 TDD 修） | 总是 | 验收与修复分离 |

## 指令形状

```
逐页 {截图/预览}，与 {目标/设计稿} 对比，检查 {层级/间距/一致性/可访问性}；
在 {多视口/多状态} 下确认。
```

**V5 的关键句**（样本原话抽象）：
```
视觉截图这轮没做成，当前会话没有暴露可用的 Browser 工具；
我用构建和 HTTP 冒烟兜住了发布面。
```
```
这是本机 Chrome/网络层限制，不是站点已经返回错误。
```

**关键句**：`这是 {工具/环境} 限制，不是 {产物} 有问题`。缺了它，会把环境问题误报成产物缺陷。

## 条件变体

| 条件 | 变体 | 差别 |
|---|---|---|
| 有截图工具 | **完整型** | 多视口截图 + 对比 + 批判 |
| 截图工具不可用 | **兜底型** | 标证据边界 + 构建/HTTP 冒烟兜住 |
| 有设计稿/原型 | **还原型** | 像素级还原对比 |
| 无参照物 | **清单型** | 用可访问性/一致性清单逐项核 |
| 报表/文档产物 | **抽检型** | 渲染抽检关键页可读性 |

## 反例与坑

- 只看代码不看渲染 → 漏掉渲染层问题（如资源路径错导致图裂）。
- 只看一次截图 → 漏掉状态相关偏差（hover / 空状态 / 移动端）。
- **截图不可用就宣称"没问题"** → 无证据的结论。
- **把环境限制误报为产物缺陷** → 修错地方。
- **边界**：纯后端/无 UI 产物的任务，不适用。

## 案例（抽象）

- 页面渲染抽检：发现案例页引用的图片路径错（`assets/screenshots/x.png` 实际在 `assets/x.png`），顺手修 build 路径。
- 报表渲染抽检：确认目录页、字段字典、输出清单在实际渲染中可读。
- 截图被网络层拦截：明确标注"本机网络层限制"，改用 HTTP 线上验证 + 本地真实浏览器验证作为证据边界。
