# 经验卡 · 阻塞报告与替代路径（跨类纪律）

> **本卡是跨类纪律。** 数据里第二跨类的行为：**53%** 的会话报告了阻塞/边界，且其中 **63% 同时给出替代路径**。

- **类型**：跨类纪律
- **身份**：跨三岗
- **support**：报阻塞出现在 **1,474/2,794 = 53%** 会话中；其中 **732/1,168 = 63%** 同时含"改用 / 替代 / 兜住 / 适配"动作
- **置信级**：**高**（53% 覆盖 + 报阻塞与替代强耦合）
- **脚手架判定**：**涌现**。`受限于`(0 配置) · `无法验证`(0) · `偏离`(0) · `回查`(0) 均不在配置里
- **口径**：全量

## 场景

执行中遇到阻塞：工具不可用、环境不对、权限不足、网络受限、依赖缺失。此时最容易出两种错——**硬撑**（假装没阻塞）或**卡死**（停下来等）。

## 问题

- 隐瞒阻塞 → 交付一个看似完成、实际有洞的结果。
- 卡在阻塞上 → 什么也不做。
- 把环境问题当产物缺陷 → 修错地方（见卡 12）。
- 不标证据边界 → 用户以为全验过了。

## 解决方案（收敛解）

**报告阻塞 + 立即给替代路径 + 标明证据边界。** 三者一起，缺一不可。

核心：**报阻塞不是为了停手，是为了换条路走完。**

## SOP（每步带独立 support）

| 步 | 动作 | support | 触发 | 决策点 |
|---|---|---|---|---|
| P1 | **报告阻塞**：是什么、为什么（工具/环境/网络） | **20/20** | 遇阻时 | 不报 → 交付带洞 |
| P2 | **立即给替代路径**：改用 / 退回 / 兜住 / 降级 | **13/20（16/20 含变体）** | 遇阻时 | 只说"做不了" → 不合格 |
| P3 | **标明证据边界**：哪些验了、哪些没验 | 12/20 | 总是 | 混标 → 误判已验证范围 |
| P4 | **正确归因**：环境缺口 ≠ 代码失败 | 11/20 | 总是 | 误归因 → 修错地方 |
| P5 | **收窄替代方案**：不扩依赖、不碰越界表面 | 5/20 | 用替代时 | 临时装依赖 → 进隔离环境 |
| P6 | **走新路径重新验证并报告** | 6/20 | 替代后 | 换了路不验 → 不知成没成 |
| P7 | 把缺口记为**下一轮动作**，不静默丢弃 | 6/20 | 有缺口时 | 静默丢 → 假装完成 |
| P8 | 不隐瞒、不假装完成 | **20/20** | 总是 | 谎报 → 信任崩塌 |

## 指令形状

```
{阻塞} 是 {原因}；因此我会 {替代路径}，并把 {缺口} 标为 {待验证/证据边界}。
```

典型实例（来自真实会话，已抽象）：
- `本机 Chrome 对线上 HTTPS 握手被重置…这是本机网络层限制，不是站点已经返回错误。再试 Playwright 截图路径；如果也被拦截，就以 HTTP 线上验证 + 本地真实浏览器验证作为证据边界说明。`
- `视觉截图这轮没做成…我用构建和 HTTP 冒烟兜住了发布面。`
- `一个现实阻塞是本机尚未安装 Git LFS，我会先把需要 LFS 的规则和校验落地。`
- `计划本身没有阻塞性缺口；唯一偏离是当前目录并非 Git 仓库，因此不会创建 worktree。`

**关键句**：`{阻塞} 是 {原因}；因此我会 {替代路径}`。**报阻塞必须带下一步。**

## 条件变体

| 阻塞类型 | 替代路径 |
|---|---|
| 工具不可用 | 改用等价原生命令；标注能力降级 |
| 网络/证书受限 | 改用本地渲染 / HTTP 冒烟；标证据边界 |
| 权限不足 | 停手报告（**注：此条在数据中未获证实，0/20**，仅作常识补充，不作为经验主张） |
| 依赖缺失 | 隔离临时安装，不进项目依赖 |
| 环境非预期（非 git 仓） | 记录偏离，跳过相关步骤但完成其余 |
| 大文件/传输卡住 | 换传输方式（scp / tar / dd），逐次验证 |

## 反例与坑

- **只报阻塞不给路径** → 等于卡死。
- **隐瞒阻塞** → 交付带洞。
- **把环境限制当产物缺陷** → 修错地方（卡 12）。
- **不标证据边界** → 用户以为全验过。
- **为绕过阻塞而越权** → 权限不足时应停手，不是造替代品。
- **边界**：无。这是全类通用纪律。

## 案例（抽象）

- 截图被网络层拦截：标"本机网络层限制"，改用 HTTP 线上验证 + 本地真实浏览器，明确证据边界。
- 缺 Git LFS：先把规则和校验落地，标"发布资产前需安装验证"。
- SSH 传输卡住：先查远程是否有部分写入，再换流式 tar / dd 上传。
- 目录非 git 仓：记录偏离，跳过 worktree 与提交，其余完整执行。
