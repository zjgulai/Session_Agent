# 经验卡 · 证据锚定（跨类纪律）

> **本卡是跨类纪律。** 数据里第三跨类的行为：**60%** 的会话把结论锚定到具体位置（file:行号 / 路径 / 命令）。

- **类型**：跨类纪律
- **身份**：跨三岗
- **support**：出现在 **1,688/2,794 = 60%** 会话中
- **置信级**：**高**（60% 覆盖 + 与只读 80% 的 54% 重合，是"证据优先执行"簇的第三面）
- **脚手架判定**：**涌现**。`行号`(0 配置) · `回查`(0 配置) 均不在配置里；`file:` 在配置里出现（技能文档），但**主动标 file:行号 的做法**不在配置
- **口径**：全量

## 场景

说了"这里有风险""这里有问题""这里没问题"——然后别人（或未来的自己）问：在哪看的？

## 问题

- 只说结论不说位置 → 无法复核。
- 说"在代码里" → 等于没给，得全文搜。
- 复核时找不到 → 结论等于没做。

## 解决方案（收敛解）

**每条结论必须带回查路径：file:行号 或 命令 + 输出。**

核心：**证据不是"我读了"，是"读到的东西在哪"。**

## SOP（每步带独立 support）

| 步 | 动作 | support | 触发 | 决策点 |
|---|---|---|---|---|
| A0 | **先声明范围**（repo / branch / commit SHA / 工作目录） | 6/20 | 总是 | 无范围 → 结论无处核对 |
| A1 | **每条发现带 locator**（file:行号 / 路径 / 命令 / URL） | **20/20** | 总是 | 只说"在代码里" → 不合格 |
| A2 | 审计/实现用**绝对路径**；review-commit 用 **branch+SHA** | 绝对 11/20 · SHA 7/20 | 看任务类型 | 混用 → 复核找不到 |
| A3 | 行号要精确（不是概数）；可能漂移时标 commit SHA + 行 | 9/20 严格 file:line | 有代码时 | 行号漂移 → 锁 SHA |
| A4 | **提炼承重值引用**（`200`/`exit 0`/`failures=0`），不贴原始终端全量 | 14/20 | 有命令时 | 只贴形容词不贴值 → 无法复核 |
| A5 | **命令要可重跑**（带命令名 + 配置/参数） | 12/20 | 有命令时 | 不可重跑 → 结论悬空 |
| A6 | **absence 也是证据**：说出"搜了什么、没找到" | 7/20 | 有负结论时 | 不标缺口 → 假装完整 |

**注意 A4 的修正**：不是"贴原文"，是**提炼承重值**。独立复现确认 **0/20 贴原始多行终端输出**。

## 指令形状

```
[{severity}] **{claim}**：[{path}:{line}] {observed value}；{consequence/root cause}；{action}。
```

典型实例：`**P1**：collect.py:100 超时后仅返回已完成批次，但仍在 collect.py:322 持续轮询尚未批。`

**不变骨架**：**claim → locator → observed fact → implication → action**，locator 紧邻 claim，不在段尾。

**A4 的关键句**（修正后）：`{output} = {200/exit 0/failures=0}`——只引承重值，不贴原始终端全量。

## 条件变体

| 条件 | 变体 | 差别 |
|---|---|---|
| 源码文件 | **file:行号** | 精确到行 |
| 配置文件 | **路径 + 具体字段值** | 行号可能不够（JSON/YAML） |
| 命令输出 | **命令 + 输出片段** | 贴原文，不做二次解释 |
| 浏览器/UI | **页面 URL + selector/截图** | 无行号可引 |
| 行号可能漂移 | **commit SHA + file:行** | 锁定版本 |

## 反例与坑

- **只说"在代码里"不标行号** → 无法复核。**实际数据：0/20 出现这种裸引用**——说明已被内化为纪律。
- **贴整段终端输出** → 噪声淹没信号。正确做法是**提炼承重值**（`200`/`exit 0`/`0/26`）。
- **行号概数** → 复核时找不到。
- **只转述不贴值** → 不可信。
- **absence 不标** → 假装完整。正确做法："搜了 X、没找到 Y、标为缺口"。
- **边界**：无文本产物（纯 UI 审查）时，用 URL/截图替代行号。
