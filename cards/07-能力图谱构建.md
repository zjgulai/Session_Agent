# 经验卡 · 能力图谱构建

- **身份**：Agent 全栈
- **问题类**：把一个已有系统/技能库的"能力"盘清楚，找出覆盖与缺口
- **support**：合并语义类 **31 会话**（全量 2,794）
- **全量 support（合并类）**：G2 锁状态 94% · G5 覆盖缺口 94% · G1 定性盘点 84% · G3 多视角 71% · G4 并行交叉 71% · G8 确认门 71% · G6 矩阵路线 65% · G7 NO-GO 13%
- **置信级**：中（见 `../05-support-全量.md`）
- **脚手架判定**：**部分脚手架**。`Graphify` / `skill-creator` / `data-analytics` 等技能被用作工具；但"能力图谱 + 覆盖/缺口 + 成熟度矩阵"的组织方式是涌现
- **口径**：样本级

## 场景

接手或重构了一个系统/技能库，要回答"它到底有哪些能力、覆盖到哪里、缺口在哪"。

## 问题

- 只做代码走查 → 看不清能力边界。
- 只列功能清单 → 看不出覆盖与缺口。
- 不做分类 → 能力互相重叠，无法编排。

## 解决方案（收敛解）

**把它定性为"能力盘点 + 审计 + 设计"，不是代码走查。** 先锁真实状态 → 多视角 MECE 检查 → 标覆盖与缺口 → 交付图谱+矩阵+路线图。

## SOP（每步带独立 support）

| 步 | 动作 | support | 触发 | 决策点 |
|---|---|---:|---|---|
| G1 | **定性**：把任务当成"能力盘点 + 审计 + 设计" | — | 总是 | 只做代码走查 → 退回，重定性 |
| G2 | 锁定真实状态与既有约束（读项目规则、历史审计） | 状态族 | 总是 | 有既有图谱 → 复用，不重造 |
| G3 | **多视角不重叠拆解**（架构 / 数据流 / 运行时 / 质量证据 / 可复用工作流 / 产出） | 复现门 5/11（显式"MECE"仅 1/11） | 总是 | 视角 <3 → 覆盖不全；视角重叠 → 重拆 |
| G4 | 并行只读审查，每视角独立；**主线程交叉核验，不照单全收** | 复现门 6/11 | 视角 ≥3 | 视角互相污染 → 拆开 |
| G5 | **标覆盖与缺口**，带证据（file:line / 严重度 / 复现） | 覆盖 26/32 · 缺口 19/32 | 总是 | 缺口不标 → 图谱无用 |
| G6 | 交付：能力图谱 + **矩阵/路线图/TODO**（不止图谱） | 复现门 9/11（core 6/6） | 总是 | 只有图谱没路线 → 不可执行 |
| G7 | **设 NO-GO 规则**：未闭环的高风险项标 NO-GO | 复现门 3/11 | 有高风险项 | 高风险未标 → 假性通过 |
| G8 | **写入/删除/部署前设人工确认门**，先列候选 | 复现门 4/11 | 有破坏性动作 | 未确认 → 不动手 |

## 指令形状

```
深度检查当前项目，识别当前项目的能力图谱，检查当前项目状态，
提出每个节点的优化方案和完善建议。
```

模型侧展开：

```
我会把这次工作当成"能力盘点 + 架构审计 + 设计"，而不是只做代码走查。
先锁定 {真实状态} 与既有约束，
再把工作拆成 {N} 条不重叠的视角（架构 / 数据流 / 运行时 / 质量证据 / 可复用工作流 / 产出），
并行启用只读子任务，主线程交叉核验、不照单全收；
输出明确区分 {已实现 / 已验证 / 被阻塞 / 仅规划}，
并给出 {矩阵 / 路线图 / TODO}。高风险未闭环标 NO-GO，写入前设人工确认门。
```

**关键句**：`而不是只做代码走查`。缺了它，图谱退化成文件清单。

## 条件变体

| 条件 | 变体 | 差别 |
|---|---|---|
| 系统已重构 | **验证型** | 先弄清重构后的图谱，再审计脆弱点 |
| 逆向工程 | **逆向型** | 从产物反推能力，再设计可复用元方法 |
| 技能库 | **技能型** | 按域分类技能，标覆盖与缺口，编排工作流 |
| 有既有图谱 | **复用型** | 挂到既有图谱，不重造 |

## 反例与坑

- 只做代码走查 → 看不清能力边界。
- 只列功能清单 → 看不出覆盖与缺口。
- 不标缺口 → 图谱没有决策价值。
- 只有图谱没有路线图 → 不可执行。
- **本类最常见的证据升级**：`代码存在 ≠ 功能完成 ≠ 已验收`、`图谱有节点 ≠ 可用`（见 [卡 12 证据升级拒绝](12-证据升级拒绝.md)）。
- **边界**：单一功能模块、无"能力面"概念时，不适用。

## 案例（抽象）

- 重构后的网站：弄清能力图谱 + 对抗性审计脆弱点。
- 逆向工程项目：从洞察报告反推可自动化的能力链，设计元方法。
- 技能库：按域分类，标覆盖/缺口，串成工作流。
