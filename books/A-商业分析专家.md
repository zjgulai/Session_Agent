### 10 · 视觉验收技法（跨类技法）

**收敛解**：**渲染抽检 + 像素/结构对比 + 证据边界诚实。**

**SOP**：搭真实渲染环境 → 截图（多视口多状态）→ 对比参照 → 批判性检查偏差 → 渲染抽检可读性 → **截图不可用则诚实标边界 + 替代证据兜住** → 标注本地 vs 线上 → 清理临时资源 → 锁进回归测试。

**关键句**：`这是 {工具/环境} 限制，不是 {产物} 有问题`。缺了它，会把环境问题误报成产物缺陷。

### 06 · 内容提取与再创作（本册核心）

**收敛解**：**产物是结构化资产，不是报告。** 只读盘点 → 拆层次 → **区分事实与候选** → 可追溯校验 → 落成目录/模板/字段 → 分类去重。

**SOP**
1. 只读盘点来源，不写文件。
2. 拆成可交付层次（解剖 + 萃取）。
3. **严格区分"来源事实"与"候选设计"**，不混为一谈。
4. **可追溯校验**：逐项回到原文 / 原始 JSON / 运行记录。
5. **落成结构化资产**：目录 + 模板 + 字段 + 清单。
6. 分类与去重。
7. 只读边界（不调用生产服务、不改原文件）。

**全量 support**：E5 结构化产物 88% · E1 只读盘点 84% · E4 可追溯 82% · **E3 区分事实与候选 80%**。

**关键句**：`不把 {来源事实} 和 {候选设计} 混为一谈`。

**注意**：复现门指出本协议**比类名更宽**——它是通用的"证据优先的只读提取协议"，也适用于审计与评审。

## 本册的方法论要点（从语料观察）

- **竞品研究的产物是"结构化资产"，不是报告**：反复出现"提取品牌资产 → 结构化 → 可复用"的形状。
- **调研默认只读**：本册的问题几乎都适用只读协议。
- **警惕"假性证据"**：品牌声量、榜单、README 声明都是代理指标，不等于事实（这条来自你自己的插件研究项目）。
